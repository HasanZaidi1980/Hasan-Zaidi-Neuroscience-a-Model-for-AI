# Lab 4: Modeling the Fundamental Unit of Computation
### What I Did
I built a Leaky Integrate-and-Fire (LIF) neuron simulation from scratch using Python. I modeled membrane potential decay, spike thresholds, and hyperpolarization (refractory periods) to see how a single neuron acts as an evidence-based decision-maker.

### What I Learned
This lab changed my perspective on AI as simple math. I realized biological computation is about timing and energy balance. I learned that the time constant ($\tau$) effectively acts as the neuron's "memory," determining how long it retains input before it leaks away.

### Challenges Faced
Capturing the instability of neural signals was difficult. I found that tiny changes in input current or thresholds can completely silence a neuron, revealing the fragility and precision required for neural coding.
