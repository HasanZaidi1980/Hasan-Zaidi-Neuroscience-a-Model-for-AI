# Lab 2: Consensus and Voting in the Neocortex
### What I Did
In this lab, I simulated the core concepts of the "Thousand Brains Theory" by building a model where multiple cortical columns "vote" to reach a consensus on object recognition. I used Python to create sensory input for objects like a "cup" or "phone" and added noise to test the robustness of distributed representations.

### What I Learned
I learned how collective intelligence emerges from distributed units. This lab demonstrated that even with high noise in individual columns, a system can achieve high confidence through a voting mechanism. It highlighted the difference between a "frozen" AI model and a dynamic, predictive biological brain.

### Challenges Faced
One major challenge was realizing how much this simplified model misses—specifically the spatial logic provided by reference frames, which are essential for true object manipulation.
