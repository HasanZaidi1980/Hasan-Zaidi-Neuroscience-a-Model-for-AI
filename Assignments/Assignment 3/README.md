# Assignment 3: Mapping Biological to Artificial Elements
### The Problem
I needed to perform a comparative analysis of how mathematical abstractions in Artificial Neural Networks (ANNs) map to actual biological neural circuits.

### My Approach
I created a mapping table for components like dendrites (input weights), axons (output connections), and synapses. I also analyzed the role of hierarchical organization and the amygdala's role in emotional processing.

### Results & Meaning
I found that while ANNs are successful abstractions, they lack the specialized feedback loops (like the amygdala-cortex connection) that allow for real-time risk assessment and adaptive behavior in biological systems.
