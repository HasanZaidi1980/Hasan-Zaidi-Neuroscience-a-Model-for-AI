# Assignment 4: Interactive Neural Dynamics
### The Problem
This assignment explored how sharply firing rates drop near thresholds and how neural coding depends on precise parameter balance.

### My Approach
Using the Wolfram Language and `Manipulate` functions, I created a simulation where I could drag sliders to change time constants and thresholds in real-time. This transformed abstract equations into tangible phenomena.

### Results & Meaning
The results showed that biological intelligence arises from neurons managing energy and leaks rather than just executing static code. The simulation revealed that tiny environmental changes can silence a signal, emphasizing the need for robust neural architectures in bio-inspired AI.
